# V1.1 设计系统

`src/mobile.css` 集中定义 V1.1 Token 并统一覆盖保留组件的外观；原 `style.css` 保留旧组件结构和兼容样式。编辑器独立为 `src/WorkoutEditor.tsx`，按需加载，离线预缓存也包含该模块。没有新增运行依赖。

| 触控   | 48px控件、44px图标操作              | 不依赖悬停       |

布局以单列为手机基线，桌面保留侧栏及合理分栏。底栏、页边和编辑器应用 safe-area；编辑器以 VisualViewport 响应键盘变化，只保留一个滚动面。完成按钮处于正常文档流，不在键盘上方固定盖住输入。UI 的实际键盘、状态栏及动态工具栏表现保留真机验收。

输入框16px及以上避免常见 Safari 自动放大；重量/次数字段使用 decimal/numeric inputMode，独立保留输入文字，避免小数输入中途被数字格式化重置。焦点不因草稿写入重新挂载。错误就地说明并保留输入，保存失败可重试。移除有内容的组、动作、训练，替换已填类型、覆盖恢复均有确认。

图表沿用轻量 SVG，无新图表库。力量图只显示相同配置，提供4/12周/全部；记录和力量历史分批显示，避免长历史一次渲染全部。动画沿用 reduced-motion 限制，没有增加毛玻璃、复杂渐变或追踪 SDK。

五页均使用同一套卡片、按钮、标签、空态和字体层级。首页突出下一次训练与本周次数；记录展示A/B/C与可继续草稿；趋势优先同器械与身体变化；AI优先导出与可解释规则；设置突出备份及计划/身体入口。
