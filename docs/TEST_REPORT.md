# 测试报告

日期：2026-10-30。已有本地验收：18项单元/数据测试、16项Chromium/WebKit手机尺寸场景通过。实际iPhone Safari人工验收和真人2–3分钟耗时仍待执行。

覆盖：训练创建/修改/删除、不同重量组、草稿刷新、真实浏览器进程重启、目标确认与历史分离、身体指标、周报、完整JSON、关联验证、重复合并、错误文件拒绝、事务写入失败回滚、演示隔离、同条件比较、训练量、7/28天包边界、手机布局、离线冷开与编辑、实际新版本SW激活后保留草稿。

发布适配：构建base使用 /fitness-os/；manifest id/start_url/scope、图标、apple-touch-icon、SW注册范围和导航回退均匹配仓库子路径。静态资源不包含用户数据库、JSON备份或任何私钥。本轮公开文件采用31项白名单；排除本地证书、机器专用脚本、原Notion交付物、缓存和测试输出。

GitHub Actions每次发布重新执行18项数据测试和生产构建。GitHub Pages实际HTTPS访问、资源状态及SW子路径离线检查需在部署完成后记录结果，不能预先宣称线上通过。

安全审计：运行依赖0，全量1项低危构建依赖deepmerge，详见已知限制。没有盲目升级依赖。

自动化测试使用临时隔离数据库和浏览器profile，不读写用户真实训练库；自动填表耗时不等于真人速度。手机真实验收按[清单](IPHONE_CHECKLIST.md)记录。备份步骤见[指南](BACKUP.md)。
