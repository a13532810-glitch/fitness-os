# 备份与恢复

浏览器数据不保证永久保存。卸载 PWA、清理网站数据、存储回收、换浏览器、换域名/端口或换设备都可能使原数据不可用。iPhone 与 Mac 默认不自动同步。**每周导出，正式使用前做一次真实恢复测试。** JSON 是明文健康数据，请保存在自己的安全目录，不提交代码仓库或公开托管。

## 导出

正式空间 → 设置 → 导出完整 JSON 备份。确认 Safari「下载」或系统「文件」中确实存在且大小合理，再另外保存一份。按钮显示最近生成时间只能证明应用生成过文件，无法验证操作系统是否保存成功。演示库禁止正式备份。

## 恢复

1. 先保存当前编辑；设置 → 选择完整备份文件。
2. 应用校验格式、版本、日期、数值、稳定ID及全部关联。错误文件不能进入写入流程；当前数据保持原样。
3. 合法文件会先自动生成并触发下载**当前数据的导入前备份**，同时显示文件内数量与恢复后预计数量。
4. 默认「合并」：现有ID一律保留；新ID加入；同ID不同内容计冲突并保留当前版本。重复导入不会复制出多条。同ID旧版本不能通过合并撤销本地编辑。
5. 只有要完整替换时才选「覆盖」。切换方式会重新生成预览和导入前备份，必须再次确认文件已保存，并准确输入「覆盖当前数据」。覆盖会删除当前库里备份没有的记录。
6. 确认导入前备份已保存成功，点击确认恢复。原子事务内重算目标数据、复核预览后是否变化、写入并核对八表数量；任一步失败回滚，不留半套关联。
7. 核对恢复成功信息的训练、实际组、动作、身体指标、目标、周报数量；打开历史抽查日期、器械、每组不同重量/次数与备注。
8. 在设置勾选「我已实际完成备份恢复，并核对训练与组数」。这是人工声明，应用不会假装已自动验证用户磁盘文件。

预览后不要在其他标签页或设备同步工具中修改数据。发现数据变化后重新选择文件，重新下载导入前备份。iPhone 某些浏览器若未自动下载，请用「再次下载导入前备份」并检查文件；没有文件就不要确认恢复。

## 安全的首次恢复演练

在正式空间还空白时导出空白备份。创建一条**自己实际完成过**的训练或草稿，不要编造真实成绩。再次导出并保存。用合并方式导入同一文件，核对没有重复；也可在另一个独立浏览器空间导入，核对数量与逐组成绩。若要验证覆盖回退，先确认两份备份确实保存，再覆盖导入较早版本，核对差异。不要使用演示数据作为正式备份测试。

跨设备搬迁：源设备导出，安全传递文件到目标设备，目标设备先备份再导入。两端不会自动同步；同一ID在两端编辑后，合并会保留目标设备当前内容。需要选定权威版本并谨慎使用覆盖，不宣称已解决双向同步冲突。
