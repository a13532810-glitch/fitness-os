# 已知限制

- 实际iPhone Safari、主屏幕系统行为、数字键盘、后台挂起、备份文件保存及真人2–3分钟录入仍需逐项真机验收。自动化通过不能替代。
- 浏览器存储可能被清理或回收；卸载PWA、换设备/协议/域名/端口可能导致数据不可用。每周备份，正式使用前测试恢复。
- iPhone与Mac不自动同步。导出JSON为明文，需要用户安全保管；应用不自动上传健康数据。
- 混合重量逐组保留，暂不自动判定力量变化；不同器械/动作方式不直接比较重量。不预测肌肉增长。
- 修改训练内器械/方式仅属于当次快照；常用设置在计划编辑器维护。
- 合并导入按稳定ID保留现有内容，不能作为双向同步；旧版本回退需要明确覆盖确认。文件上限20MB。
- 编辑已完成记录时临时填写不完整会保留上次有效数据库版本并提示保存失败，需填完整、清空该组或重试。
- GitHub Pages同一账号的其他项目与本项目共享origin；浏览器本地数据的隔离以origin为边界。公开URL不是访问控制，不要将敏感JSON提交任何公开仓库。
- GitHub Pages的静态响应缓存头由平台控制，不能直接套用其他托管商的_headers配置。Service Worker采用提示更新，不在更新时清库。
