# V1.1 已知问题与待验收项

- 真实 iPhone Safari、主屏幕独立运行、动态工具栏、键盘遮挡、后台挂起、锁屏、系统重启、文件保存与真人 2–3 分钟录入仍待人工验收。模拟 Chromium/WebKit 通过不能替代。
- 无效数字保留在当前输入框并阻止关闭；请修正或清空后离开。无法由旧版数字数据模型表达的中间文本（例如只有小数点）不会写入 IndexedDB；强制结束浏览器可能丢失这种未保存的无效文本，最后有效草稿仍在。
- 编辑已完成训练时，暂时不完整的组不会覆盖上次有效数据库版本，并会提示修正。填写完整或清空整组后可继续保存。
- 器械缺失仍允许完成记录，但会提示比较可信度有限；不同器械、方式或缺失条件不判断力量提高。混合重量逐组显示，不自动换算肌肉增长。
- 主屏幕与 Safari 的存储共享行为取决于实际系统；同一账号 GitHub Pages 的其他项目可能共享 origin。不要把敏感 JSON 放入仓库。
- 浏览器存储可能被清理/回收，iPhone 与 Mac 不同步。卸载 PWA、清网站数据或改 origin 会使数据丢失/不可用，须每周备份。
- 复制提示词失败时提供可长按复制文本。iOS「文件」下载和恢复选择器须真机核对。
- 本轮不提供公开 V1.1 预览；线上仍是 V1.0。真机候选版需另行准备可信 HTTPS，普通局域网 HTTP 无法完整验收 PWA。
- 本地自动化覆盖1000次训练的页面响应和3000次训练的分析计算；这不是无限数据量或真实手机性能保证。
