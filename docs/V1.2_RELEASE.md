## 回滚依据

远端 annotated `v1.1.1` 的对象为 `05605e44e44f7e0af7de91040f9c1ab1ee4398e5`，实际代码提交为 `4a10d42c4f19d5f952fab690cec043fc860c4a8e`。此标签保持不变，是本次发布前稳定回滚点。

`v1.1-pre-v1.1.1` 仍指向 V1.1 提交 `a454577`。旧 `v1.0-pre-v1.1` 本地为 annotated 标签，远端为 lightweight 标签，两者解引用后同为 `805e67f`，不强制覆盖或重新推送旧标签。

若需回滚：

1. 停止进一步发布，保留当前 IndexedDB；在浏览器中导出当前 JSON 并确认文件保存。
2. 对本次 V1.2 merge commit 创建反向提交（`git revert -m 1 <V1.2合并提交>`），审核 diff 并运行检查；通过正常 main push 触发原 Pages 工作流。
3. 该方式恢复发布前静态代码，保留 Git 历史与已有标签；禁止 reset/force push main。
4. 保存草稿并关闭编辑器后接受 SW 更新，再核对记录与组数。不得清理网站数据、删除数据库或用旧备份覆盖新增训练。

V1.0、V1.1、V1.1.1 升级到 V1.2 再回滚的数据逐字段兼容已有自动化覆盖。本次只部署静态代码，不执行数据迁移。
