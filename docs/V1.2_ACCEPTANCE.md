## 实现

- 四个核心导航：总览、训练、趋势、AI 周报。首次进入总览；hash 保存所选页面，支持浏览器前进、后退和刷新。
- 总览右上角菜单提供数据管理、训练计划与动作库，原备份提醒卡也保留快捷入口。没有独立设置标签或演示空间切换。
- 训练记录仅展开当前动作，目标组数/次数在名称下方，有历史才显示上次成绩，有确认目标才显示额外目标。
- 每组采用独立五列：组号、重量、×、次数、垃圾桶。乘号居中且无交互；数字键盘与原校验边界不变。已填组和动作删除均需确认。
- 独立「添加动作」按钮直接进入动作库选择；可转到动作库管理/新建自定义动作。添加动作后自动展开该动作。
- 器械和座椅归入动作详情，均可不填。质量与余力勾选从日常界面移除。不同器械/方式仍按原严格规则比较，不替用户修改历史条件。
- 时长移至训练右上角菜单；疲劳与感受输入隐藏。移除大面积更多信息卡片。
- 关闭会等候保存。保存草稿、放弃本次打开后的修改、删除训练是三个不同操作。删除前下载完整恢复备份，可在数据管理合并恢复。
- 完成训练为底部吸附主按钮；沿用 visualViewport 监听适配软键盘，保留安全区内边距和输入滚动余量，单一滚动面。
- 深绿色、柔和背景、统一圆角和 44–48px 以上触控区。缩短标题、收起英文装饰标题，压缩总览计划卡，去掉无历史的空提示和重复说明。保留所有校验、存储异常、备份风险、导入冲突和破坏性确认。
- 数据管理增加显式「检查数据完整性」，保留完整 JSON 导出、预览、合并、覆盖确认、关联验证、导入前备份、主题和离线/存储工具。

## 数据审计

`src/db.ts`、`src/model.ts`、`src/backup.ts`、`src/analytics.ts` 相对基线逐字不变。保持原数据库名 `fitness-os-real`、Dexie schema 1、JSON version 1 和八张表；不执行删库或迁移，不接触演示库。

隐藏 UI 不删除字段。专项测试将虚构旧记录中的 duration/fatigue/notes/quality/reserve 写成非默认值，随后通过新 UI 编辑成绩、导出与合并恢复，核对字段、重量和次数。升级测试对全部表逐字段比较，包含完成记录和半填草稿；旧代码回滚后数据仍可读取。自动测试只用隔离浏览器和合成记录。

## 交互比较

日常流程仍为打开总览 → 选 A/B/C → 逐动作填重量/次数 → 完成。添加动作从展开更多信息、选动作、点击添加改为点击独立按钮、选动作、点击添加；操作数量保持三步，入口无需搜索大卡片。器械与训练详情由需要时主动打开，完成训练不依赖它们。备份除原提示卡入口外，还能从总览更多菜单进入。

同条件 390px 空空间实测：

| 指标 | V1.1.1 | V1.2 | 变化 |
| --- | --- | --- | --- |
| 总览文档高度 | 2515px | 1766px | 减少约 30% |
| 训练编辑器滚动高度 | 1587px | 1171px | 减少约 26% |
| 默认训练编辑器可见文本长度 | 337 字符 | 225 字符 | 减少约 33% |

这些缩减来自层级、卡片密度和按需展开，不缩小触控区。实际训练效率仍需真人验收。

页面高度与可见文本长度由 `scripts/capture-v12.mjs` 在隔离空库实际测量，数据见 `v1.2/before-layout.json` 与 `v1.2/after-layout.json`。这些指标只说明视觉密度，不作为训练效率或医学效果结论。

## 限制与回滚

- 未执行真实 iPhone 硬件验收，不能把桌面 WebKit 当作 iOS Safari。键盘、刘海安全区、Safari 工具栏、主屏幕 PWA 与后台存储策略必须按 [真机清单](V1.2_IPHONE_CHECKLIST.md) 验收。
- 自动填入十二组的耗时不证明真人能在 2–3 分钟完成，需真人计时。
- 删除恢复依赖用户妥善保存下载的完整 JSON，不保证下载文件永久可用；没有新增回收站或云同步。
- 沿用本地 IndexedDB 的浏览器存储限制和原有多标签页编辑机制。备份不能省略。
- 原 V1.1 / V1.1.1 报告保留为历史证据；本报告和 README 的最新版本状态优先。
- 发布需另行授权。回滚代码可恢复 `4a10d42` 的静态资源，数据库无需降级或清空；已在隔离环境验证升级及回滚。不得为回滚清理网站数据。
