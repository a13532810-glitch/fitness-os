自动化覆盖桌面运行的 Chromium 与 WebKit，不等同真实 iOS Safari。V1.2 尚未部署；以下检查需在获准发布后的候选环境或受信任的本地 HTTPS 环境执行，不要为体验候选版清理正式网站数据。

- [ ] 先从现有网站导出 JSON，确认文件已保存在「文件」。
- [ ] Safari 浅色、深色各检查一次，总览、训练、趋势、AI 周报四导航可触控。
- [ ] 总览右上角更多菜单能找到数据管理、训练计划与动作库。
- [ ] A/B/C 各开一份草稿。目标组数正确，无历史时不出现空提示。
- [ ] 重量输入出现小数键盘；次数出现整数键盘；× 在两个输入框之间。
- [ ] 对最后一组输入，键盘和 Safari 工具栏不遮住输入与完成按钮；收起键盘后页面高度恢复。
- [ ] 检查刘海、横屏、底部 Home 指示条、系统大字体。
- [ ] 添加组、取消删除已填写组、确认删除空白组、添加动作、删除动作。
- [ ] 从添加动作进入管理动作库，新建自定义动作，回草稿添加它。
- [ ] 自愿填写器械与座椅，完成后新训练记忆；换器械后不展示另一器械成绩。
- [ ] 关闭保存草稿、刷新、切后台再返回、彻底关闭 Safari 后重开，输入仍在。
- [ ] 修改草稿后使用「放弃本次修改」，恢复本次打开前的内容；确认不会删除原记录。
- [ ] 填四动作十二组，真人计时是否能在 2–3 分钟内完成。记录实际耗时。
- [ ] 完成、重新编辑；时长可选；历史疲劳、备注不因编辑丢失。

- [ ] 添加到主屏幕后冷启动，断网录入，重新联网后数据仍在。
