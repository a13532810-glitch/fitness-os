# Fitness OS V1.2.1 视觉规范

以原生移动端数据阅读与操作效率为目标；无外部字体、图片、付费服务或云端数据依赖。

| 项目 | 规范 |
| --- | --- |
| 背景 / 卡片 | #F8F9F6 / #FFFFFF |
| 正文 / 品牌 | #1C3029 / #245C46 |
| 柔和底色 / 分隔线 | #EAF0EA / #E5E9E3 |
| 次要文字 | #65736B；保留足够对比度 |
| 深色 | 沿用系统和手选深色，背景 #151C18，正文 #EDF3ED；跟随系统亦有完整旧深色变量 |
| 字体 | 系统中文字体，正文 16px，辅助 12–14px，标题 25px，指标 23–34px；数字 tabular-nums |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32px；列表以分隔线区分，避免套卡 |
| 圆角 | 卡片 16px、控件 10px、弹层沿用 24px，边线 1px |
| 阴影 | 0 2px 14px #1C302904，仅用于轻层次，无玻璃或装饰渐变 |
| 图标 | lucide 线性图标，常用 16–20px；关闭图标 19–20px |
| 触控 | 关闭、删除等至少 44×44px；单行动作 summary 58px，不能仅靠字号缩小提高密度 |
| 输入 / 按钮 | 至少 44px，训练数字输入保留原独立文本和数值校验；使用 decimal / numeric 键盘 |
| 焦点 | 2px 品牌色外轮廓、2–3px 偏移；不移除键盘焦点 |
| 弹窗 | 原生 dialog、内容单一滚动、可视视口 resize 高度适配；计划保存随文档流，不浮盖最后输入 |
| 底部操作 | 训练保留吸附完成操作，env(safe-area-inset-bottom)，原 visualViewport 键盘适配与滚动余量 |
| 导航 | 四导航、当前页高亮与文本并存；顶部品牌不重复页面标题；桌面保留侧栏 |
| 图表 | 原始真实数值，独立比较条件，至少两点显示趋势；不展示虚构增长率或插入演示记录 |
| 空状态 | 左对齐短文案，不使用大插图；身体指标采用双指标卡和每项一行数据不足提示 |
| 动态效果 | 遵循 prefers-reduced-motion，减少动画、过渡和自动滚动 |

计划默认仅动作名与“3 组 × 8–12 次”，展开后才编辑三列数值。总览动作同一行展示名字与目标，点按展开器械、上次成绩和确认目标，保留信息入口。

目标弹窗默认动作、可选重量、组数、次数区间。高级选项保留来源、器械、方式和依据；缺少必要依据时自动展开并提示，保存仍为待确认，确认仍需明确操作。

AI 周报采用概况、导出、手动保存、历史顺序。JSON 主操作，Markdown 与复制提示词次级；没有接入自动 AI。原数据格式、来源及建议边界仍可查阅。
